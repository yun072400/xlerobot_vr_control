# Control xlerobot by metaquest and Collect data

This guide is for controlling the right arm only.

# Getting Started

## Step 1: Install LeRobot

Parts of this guide were adapted from the [LeRobot installation docs](https://huggingface.co/docs/lerobot/installation).

**Conda only**

First, install Miniforge and set up the environment:
```bash
wget "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-$(uname)-$(uname -m).sh"
bash Miniforge3-$(uname)-$(uname -m).sh

conda create -y -n lerobot python=3.12
conda activate lerobot

conda install ffmpeg -c conda-forge
```

Next, clone the VR control repository:
```bash
git clone https://github.com/yun072400/xlerobot_vr_control
cd lerobot
```

Then, install the library in editable mode. This is useful if you plan to contribute to the code:
```bash
pip install -e ".[core_scripts]"  # For robot workflows (recording, replaying, calibration)
pip install -e ".[training]"      # For training policies
pip install -e ".[all]"           # Everything (all policies, envs, hardware, dev tools)
```

Install the base LeRobot package and motor support:
```bash
pip install lerobot
pip install 'lerobot[feetech]'
```

## Step 2: Hardware setup

Parts of this guide were adapted from the [xLeRobot docs](https://xlerobot.readthedocs.io/en/latest/index.html).

First, turn on the robot by pressing the large button on the battery for a few seconds.

Check the motor ports by running the script in the repository. You should connect the motor USB or BUS.

Example: in the Ubuntu terminal located at ~/lerobot:
```bash
python src/lerobot/scripts/lerobot_find_port.py
```

Wait a moment until a list of ports appears. Then disconnect one of the motor ports and press Enter. The corresponding port will be displayed.

Then, run the following command in the terminal:
```bash
sudo chmod 666 [your port]
```

Check the camera port in a similar way.

Run the following command in the terminal:
```bash
python src/lerobot/scripts/lerobot_find_cameras.py
```

After waiting a few seconds, a list of cameras will appear and sample images will be saved. You can find the sample images in ~/lerobot/outputs/captured_images. You can also check the camera ports from the sample image name.

## Step 3: Collecting xlerobot data using metaquest control

Open the so100_data_collection_UI.ipynb notebook in the examples folder.

Execute all code blocks before Section 2: Meta Quest.

Press the Meta Quest menu button (∞) on the right-hand controller and open the browser. Access the link generated by the code executed in Section 2.

When the "Your connection is not secure." message appears, click Advanced and open the link.

You will see a green button to connect the PC and the Meta Quest headset.

- If you need to restart the code, stop the browser by pressing the Meta Quest menu button and then pressing the Stop button.

Execute Section 3 and collect data through the UI.

You must wear the Meta Quest headset and look at the hand controller to control the robot arm.

The robot arm operates only when the middle finger trigger is pressed. The index finger trigger controls the robot gripper.
